# Perchlight logo brief (2026-11-16)

- **Say:** a small light you keep on your own branch: tools that sit on your own Cloudflare account and keep watch. Name = perch + light.
- **Places:** site favicon (16/32) in light and dark browser tabs, Electron app icon (Windows .ico, macOS .icns, Linux 512 png), GitHub avatar and social preview (circle crop), README header, one-colour use.
- **Keep:** the bird + branch + lamp idea people have seen on v0.1; the night / bone / amber palette (`docs/site/DESIGN.md`).
- **Avoid:** cloud shapes, flames or anything resembling Cloudflare's mark (no affiliation implied); gradients, glows, detail that dies below 32px.
- **Current icon (v0.1) baseline:** raster with a glow; bird unreadable at 16–24px; dark tile disappears on dark grounds; no one-colour form.
