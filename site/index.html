Free tools for running your product on Cloudflare

A desktop app for your Cloudflare data, plus self-hosted tools that replace paid services: a mailing list, an update server for your app, usage alerts, crash reports, a forms backend, and more on the way. All open source, all on your own Cloudflare account, no subscriptions.

See the tools Everything on GitHub

Each tool is a separate project you can use on its own. The self-hosted ones deploy to your account with one click, and fit inside Cloudflare's free plan for most small products.

The tools

Desktop app · Windows, macOS, Linux

Perchlight

Browse and edit Workers KV and D1, build your own screens over your data without code, and run every tool below from one place.

Replaces: digging through the dashboard

Self-hosted · Workers + D1

perchlight-list

A mailing list: double opt-in signups, spam protection, and announcements through Resend, Amazon SES, Mailgun, Postmark or Cloudflare Email.

Replaces: a monthly newsletter-service bill

Source and setup

Self-hosted · Workers + R2 + D1

perchlight-updates

An update server for Electron and Tauri apps: release channels, gradual rollouts, pulling a bad release in one command, and private links for testers.

Replaces: paid update and download hosting

Source and setup

Self-hosted · Workers + D1

perchlight-guard

Warns you at 80% and 100% of every Cloudflare free-plan limit, and of GitHub Actions' free allowance, before you hit errors or a bill.

Replaces: finding out from an error page or an invoice

Source and setup

Self-hosted · Workers + D1 + R2

perchlight-crashes

Crash and error reports for desktop apps and games. Electron's crash reporter and Sentry's SDKs send to it unchanged; crashes are grouped, with one alert per new issue or regression.

Replaces: a crash-reporting subscription

Source and setup

Self-hosted · Workers + D1

perchlight-forms

A backend for your website's forms: contact, signups and file uploads, from plain HTML. Spam filtering, a spam folder, and an email or webhook for each submission.

Replaces: a paid form service

Source and setup

The desktop app

One app, all your sites

A project per site or app, each with its own Cloudflare account. Switch in one click.

Screens without code

Pick a table or a set of keys. Perchlight suggests the columns, and you choose what's shown, editable, and what each row's buttons do.

Or write them yourself

Screens are a perchlight.json file with a published schema, so you or your AI agent can write it. Imports are checked and every problem is explained.

Screens for every tool

Each self-hosted tool ships a ready-made screen file: subscribers and announcements, releases and rollouts, usage and alerts.

Download for Windows, macOS or Linux

Free and open source (MIT). Installers aren't code-signed, so your system will ask you to confirm once. How to open them.

Get updates

On GitHub, open a tool and choose Watch → Custom → Releases, and GitHub will tell you when there's a new version.
